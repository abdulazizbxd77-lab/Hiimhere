# TV Home (customizable Android TV launcher)
Open this folder in Android Studio (Koala or newer) -> sync -> Build > Build APK(s) (release is debug-signed, installable as-is).
Install: adb install app-release.apk, then press Home and choose "TV Home" > Always.
Keys: Menu / F2 / S opens Customize. Mouse hover + click, keyboard arrows/Enter, and D-pad all work.
